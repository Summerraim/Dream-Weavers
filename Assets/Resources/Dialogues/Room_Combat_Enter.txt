# 战斗房间进入对话示例
# 这是一个对话数据文件的示例说明

## 如何在Unity中创建对话数据文件：

1. 在Unity编辑器中，右键点击Project窗口
2. 选择 Create -> Dialogue System -> Dialogue Data
3. 将文件命名为 "Room_Combat_Enter" 并保存到 Assets/Resources/Dialogues/ 目录

## 对话数据配置示例：

- **对话ID**: Room_Combat_Enter
- **对话条目1**:
  - 说话者: 系统
  - 文本: 你进入了一个战斗房间！准备好迎接挑战了吗？
  - 等待输入: 是
- **对话条目2**:
  - 说话者: 系统  
  - 文本: 敌人已经出现在你面前，小心应对！
  - 等待输入: 是

## 其他房间类型的对话ID：

- 休息房间: Room_Rest_Enter
- 道具房间: Room_Props_Enter  
- 事件房间: Room_Events_Enter
- Boss房间: Room_Boss_Enter

## 注意事项：

1. 确保所有对话数据文件都保存在 Assets/Resources/Dialogues/ 目录下
2. 文件命名必须与DialogController.cs中的映射一致
3. 对话数据文件需要继承自DialogueData ScriptableObject
