 Dream Weavers：织梦者
编织梦境，驯养心兽，构筑属于你的无限可能

《Dream Weavers：织梦者》是一款融合了 宠物收集、策略战斗 与 Roguelike探险 的回合制游戏。
你将扮演主角 Solo，在梦幻般的世界中净化并培养名为 “心兽” 的奇幻生物，通过不断探险解锁更多心兽与羁绊，组建独特队伍，挑战层层递进的关卡与首领。

✨ 核心特色
🎴 心兽收集与培养
每只心兽拥有独特属性、技能与成长路径，可收集、净化、培养，组建专属阵容。

⚔️ 深度策略战斗
采用1v1轮换对战，6只心兽轮番上阵。每只心兽携带多个技能，涵盖伤害、控制、治疗、减益等丰富效果。

🧩 羁绊构筑系统
特定心兽组合可激活羁绊效果，在战斗中实时生效。如“狂战士”“森林之子”“虚空遗民”等，鼓励探索阵容搭配。

🗺️ Roguelike探险循环
随机生成地图节点，包含战斗、首领、技能、道具、休息等房间。单局内永久成长与风险决策并存。

📚 多重世界观与叙事
融合森林、冰川、城堡、虚空四大场景，每个心兽拥有独特背景，剧情与战斗交织。

🎮 玩法速览
探险 – 在随机地图中选择路径，遭遇各类事件。

战斗 – 回合制对战，运用技能与羁绊击败敌人。

收集 – 胜利后捕获心兽、获取技能与道具。

构筑 – 搭配心兽、激活羁绊，形成独特战术体系。

成长 – 通过局内强化与永久升级，不断突破更高难度。

🧠 策略维度
心兽定位：输出、坦克、控制、治疗，四种角色明确分工。

技能搭配：基础技能、常规技能、大招技能，合理分配法力与冷却。

状态联动：中毒+治疗抑制、易伤+爆发伤害、沉默+法力流逝……

羁绊协同：多套羁绊体系自由组合，构筑无限可能。
